<Update label="v1.0.1">
  **Chatbox message queue**

  You can now queue up messages to make sweeping changes without needing to wait for your agent to respond to the last message.
  
  This update includes:
  - Queued messages displayed in a dedicated strip above the prompt
  - Per-message queue controls (cancel, plus send-now when idle)
  - Slightly reduced chat sidebar width for a cleaner editor layout
</Update>
